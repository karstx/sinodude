# sinodude-serial

| Feature | Supported |
|---|---|
| Read flash | Yes |
| Write flash | Yes |
| Mass erase | Yes |
| Sector erase | Yes |
| Read, write and erase data EEPROM | Yes |
| Read and apply read/write protection | Yes |
| Unlock with key | Yes |
| Customer ID, operation number, customer option, serial number | Yes |
| Boot ROM (ISP) area (`--boot_rom`) | No |
| Target supply | 5 V |
| Link | 4-wire |
| Parts | 5 V parts; writing security bits needs security level 4 and chip type `0x07` |
