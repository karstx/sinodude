# SinoLink

| Feature | Supported |
|---|---|
| Read flash | Yes |
| Write flash | Yes |
| Mass erase | Yes |
| Sector erase | Yes |
| Read, write and erase data EEPROM | Yes |
| Read and apply read/write protection | Yes |
| Unlock with key | Yes |
| Customer ID, operation number, customer option, serial number | Yes |
| Boot ROM (ISP) area (`--boot_rom`) | Yes |
| Target supply | 3.3 V, 5 V, external |
| Link | 4-wire, 1-wire |
| Parts | 8051 only |
